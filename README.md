# Vivang Dalal

I study finance, build quantitative models, and write research. This
profile is where I publish that work.

I completed my Bachelor of Management Studies (International Business) at
Bhagwan Mahavir University in Surat, and spent the summer of 2025 at Jainam
Broking Limited.

## What I build here

- **[Global-Portfolio-and-Risk-model](https://github.com/dalalvivang/Global-Portfolio-and-Risk-model)**
  - a mean variance portfolio across 39 global multi currency equities,
  stabilised with Ledoit-Wolf shrinkage and tested through walk-forward
  out of sample backtesting.

- **[influence-of-retail-attention-on-financial-markets](https://github.com/dalalvivang/influence-of-retail-attention-on-financial-markets)** - my BMS thesis,
  testing whether retail search attention drives mutual fund flows using a
  VAR framework and Granger causality, validated against the source paper's
  own tables.

- **[research-reports](https://github.com/dalalvivang/Research-Reports-Archive)** - company and industry research, covering brokerage,
  jewellery manufacturing, and battery energy storage so far.

## How I work

I read the primary sources first, build the model myself in Python, and
check it against a benchmark I did not produce. Where a result doesn't
fully reproduce, I say so in the repository rather than hide it.

**Toolkit:** Python (pandas, NumPy, statsmodels, cvxpy, Matplotlib), Excel,
financial statement analysis.
